\chapter{SOS MAP}
\label{chap:sos-map}
\microtypecontext{protrusion=none; encoding=T5}
This chapter presents the development of the SOS map module, which provides a comprehensive mapping solution for emergency services in Ho Chi Minh City. The SOS map integrates real-time data from various sources to offer accurate and up-to-date information on emergency incidents, safe routes, and nearby resources.

\section{Problem Definition}
In emergency situations, timely access to accurate information is crucial for effective response and safety. The SOS map aims to address the following challenges:
\begin{itemize}
    \item Lack of real-time information on emergency incidents and safe routes.
    \item Difficulty in locating nearby emergency resources such as hospitals, police stations, and fire departments.
    \item Need for a user-friendly interface that can be easily accessed during emergencies.
\end{itemize}
