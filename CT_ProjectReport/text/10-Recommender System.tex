\chapter{}{Recommender System}
\label{chap:recommender-system}
The Recommender System module focuses on developing an AI-powered recommendation engine that suggests personalized points of interest (POIs) such as hotels, restaurants, and attractions to users based on their preferences and context. Leveraging large language models (LLMs), the system generates tailored recommendations by analyzing user inputs and parsing responses from the LLM.

\section{Problem Definition}
Travelers often struggle to find suitable POIs that match their interests, budget, and itinerary constraints
. The Recommender System aims to address the following challenges:
\begin{itemize}
    \item Understanding user preferences and context to provide relevant recommendations.
    \item Integrating with LLMs to generate natural language suggestions.
    \item Filtering and ranking recommendations based on multiple criteria such as distance, ratings, and cost
    \item Providing a seamless user experience through an intuitive interface.
\end{itemize}

\section{Framework \& Tech Stack}
The Recommender System module is built using the following technologies:
\begin{itemize}
    \item \textbf{Backend:} Python with Flask framework for handling API requests and
    \item \textbf{LLM Integration:} OpenAI GPT-4 API for generating recommendations based on user inputs.
    \item \textbf{Data Storage:} MySQL database for storing user preferences and
    \item \textbf{Recommendation Algorithm:} Custom filtering and ranking algorithms implemented in Python.
    \item \textbf{Frontend Visualization:} React.js for rendering recommendation results to users.
    \item \textbf{Containerization:} Docker for consistent deployment across environments.
    \item   \textbf{Version Control:} Git and GitHub for source code management and collaboration.
    \item \textbf{Testing:} PyTest for unit and integration testing of backend components.
    \item \textbf{Documentation:} Sphinx for generating technical documentation.
    \item \textbf{Monitoring:} Prometheus and Grafana for tracking system performance and usage metrics.
    \item \textbf{Security:} Implementation of OAuth 2.0 for secure user authentication and authorization.
    \item \textbf{CI/CD:} GitHub Actions for automated testing and deployment pipelines.
\end{itemize}
