\section{Project Value}

This project delivers a \textbf{comprehensive urban mobility solution} for Ho Chi Minh City that:

\begin{enumerate}
    \item \textbf{Reduces commute stress} by providing optimal bus routes with accurate fare and time estimates
    \item \textbf{Improves traffic awareness} through real-time congestion visualization from 100+ cameras
    \item \textbf{Enhances tourism experience} with AI-featured trip planning in natural language
    \item \textbf{Enables community safety} through the SOS alert system for incident reporting
\end{enumerate}

The integration of multiple AI technologies (computer vision, LLMs, graph algorithms) creates a synergistic system greater than the sum of its parts.

\section{What We Have Learned Through This Project?}

\subsection{Computational Thinking Insights}

\begin{enumerate}
    \item \textbf{Decomposition is Essential}
    \begin{itemize}[noitemsep]
        \item Breaking the project into independent modules enabled parallel development
        \item Each module could be tested independently before integration
    \end{itemize}
    
    \item \textbf{Pattern Recognition Saves Time}
    \begin{itemize}[noitemsep]
        \item Identifying the ``geographic proximity'' pattern led to reusable functions
        \item The caching pattern reduced load times from 30s to $<$1s
    \end{itemize}
    
    \item \textbf{Abstraction Enables Scalability}
    \begin{itemize}[noitemsep]
        \item The graph abstraction allows adding new transit modes (metro) easily
        \item The place abstraction makes the database extendable
    \end{itemize}
    
    \item \textbf{Algorithm Design Requires Trade-offs}
    \begin{itemize}[noitemsep]
        \item A* with transfer penalties balances speed vs. convenience
        \item Threshold-based classification is simple but effective
    \end{itemize}
\end{enumerate}

\subsection{Technical Lessons}

\begin{itemize}
    \item \textbf{GPU Acceleration is Critical} for real-time detection
    \item \textbf{LLMs Need Structured Prompts} for reliable JSON output
    \item \textbf{Caching Transforms User Experience} (30s $\rightarrow$ $<$1s load time)
    \item \textbf{OAuth Simplifies Onboarding} but requires careful security
    \item \textbf{Fuzzy Matching Bridges AI and Reality} (LLM output $\rightarrow$ database)
\end{itemize}
